# About Us Page

A comprehensive company overview page that tells the story of Tiger Hawk and showcases our values, team, and achievements.

## Page Structure

### 🎯 Hero Section
- **Gradient Background**: Blue gradient with white text
- **Company Tagline**: "Trusted Performance in Every Step"
- **Brand Icon**: Large lightbulb icon representing lighting solutions
- **Responsive Design**: Adapts to all screen sizes

### 📊 Statistics Section
Displays key company metrics:
- **10+ Years of Experience** (Award icon)
- **50K+ Happy Customers** (Heart icon)
- **100+ Products** (Lightbulb icon)
- **25+ Countries Served** (Globe icon)

### 📖 Our Story Section
- **Company History**: Founded in 2014, growth from small workshop to global brand
- **Mission Evolution**: From local hikers to worldwide customers
- **Current Status**: Industry leadership with cutting-edge technology
- **Visual Element**: Workshop image with shadow and rounded corners

### 🚀 Mission & Vision Section
Two-column layout with distinct styling:
- **Mission Card** (Blue theme): Focus on providing innovative lighting solutions
- **Vision Card** (Green theme): Global leadership in advanced lighting technology
- **Icons**: Rocket for mission, Globe for vision

### 💎 Core Values Section
Four key company values with color-coded icons:
1. **Innovation** (Blue) - Pushing lighting technology boundaries
2. **Quality** (Green) - Rigorous testing and high standards
3. **Customer Focus** (Purple) - Customer-centric approach
4. **Sustainability** (Emerald) - Environmental responsibility

### 👥 Leadership Team Section
Three team members with:
- **Circular Profile Images**: Professional headshots
- **Names & Positions**: Clear hierarchy display
- **Brief Bios**: Professional backgrounds and expertise
- **Responsive Grid**: Adapts from 1 to 3 columns

### ⭐ Why Choose Us Section
Six compelling reasons with unique icons:
1. **Proven Quality** (Yellow award icon)
2. **Innovation First** (Blue lightbulb icon)
3. **Customer Support** (Red heart icon)
4. **Eco-Friendly** (Green leaf icon)
5. **Safety Focus** (Purple shield icon)
6. **Global Reach** (Indigo globe icon)

### 🎯 Call-to-Action Section
- **Blue Background**: Matches brand colors
- **Two Action Buttons**: 
  - "Explore Products" (white button)
  - "Contact Us" (outlined button)
- **Compelling Copy**: Encourages user engagement

## Technical Implementation

### 🛠️ Technologies Used
- **Next.js**: React framework with App Router
- **TypeScript**: Type safety and better development experience
- **Tailwind CSS**: Utility-first styling
- **React Icons**: Consistent iconography
- **Next.js Image**: Optimized image loading

### 📦 Component Structure
- **Client Component**: Uses 'use client' directive
- **Modular Sections**: Each section is self-contained
- **Reusable Data**: Arrays for stats, values, team members
- **Responsive Grids**: CSS Grid for layouts

### 🎨 Styling Approach
- **Utility Classes**: Tailwind CSS for rapid development
- **Consistent Spacing**: Standardized padding and margins
- **Color Variables**: Semantic color usage
- **Typography Scale**: Responsive font sizes
